# Yetenekler

## Programlama Dilleri

- Python: Yasin'in ana programlama dilidir.
- SQL: PostgreSQL üzerinde aktif kullanım (şema tasarımı, sorgu yazımı).

## Teknolojiler ve Araçlar

- n8n — otomasyon ve iş akışı platformu
- Docker — containerization
- Dokploy ve Coolify — deployment yönetimi
- Ubuntu Linux ve VPS yönetimi
- OpenAI API — LLM entegrasyonları
- Scrapy ve Playwright — web scraping
- SQLAlchemy ORM — veritabanı katmanı
- FastAPI — RESTful API ve LLM tabanlı backend servisleri
- LangChain — RAG ve agent mimarileri
- Streamlit — hızlı arayüz prototipleri
- Supabase (PostgreSQL + pgvector) — RAG mimarilerinde vektör veri depolama

## Uzmanlık Alanı ve Çalışma Yaklaşımı

Yasin'in temel uzmanlığı, yapay zeka araçlarını uygulamalara entegre etmek ve bu
entegrasyonlar üzerinden akıllı sistemler ile uçtan uca otomasyon çözümleri
üretmektir. Büyük dil modellerini (LLM) n8n otomasyon platformu ile birleştirerek
monoton ve tekrarlayan iş süreçlerini otomatize eden sistemler geliştirir. Web
scraping, veri analizi ve süreç otomasyonu bilgilerini yapay zeka araçlarıyla
harmanlar.

## Uçtan Uca Sorumluluk

Yasin bu araçları projelerinde aktif olarak kullanır. Geliştirme sürecinden
deployment aşamasına kadar tüm süreçleri kendisi yönetebilir; bir proje fikrini
kod yazmaktan canlı ortama almaya kadar tek başına taşıyabilir.

## Şu Anda Öğrendiği Teknolojiler

- Hugging Face: açık kaynaklı modelleri (embedding, text generation,
  classification) Python ortamına entegre ederek OpenAI API'ye alternatif veya
  tamamlayıcı çözümler üretme.
- Arama Motoru Optimizasyonu (SEO): teknik ve içerik odaklı optimizasyon
  tekniklerini otomasyon ve içerik üretimi projelerine entegre etme.
- Yapay zeka alanı çok hızlı geliştiği için Yasin öğrenme sürecini hiç bırakmaz;
  yeni çıkan modelleri, araçları ve yaklaşımları düzenli takip edip projelerine
  entegre eder.
